# Dataset

Dataset mentah tidak disimpan di GitHub karena ukurannya besar dan dapat memiliki batasan privasi/distribusi.

## Lokasi yang diharapkan

Setelah memperoleh dataset dari pemilik penelitian, letakkan file CSV di:

    data/raw/

Nama file yang digunakan pipeline:

- `d1.csv`
- `d2.csv`
- `d3.csv`
- `d4.csv`
- `d5.csv`
- `patient.csv`
- `diagnosis.csv`
- `medication.csv`
- `physician_specialty.csv`
- `transcript.csv`
